#  Sistema de Cadastro de Clientes - CustomTkinter

Projeto desenvolvido durante meus estudos da biblioteca **CustomTkinter**, com o objetivo de aprender a criar interfaces gráficas modernas em Python utilizando programação orientada a objetos.

##  Sobre o projeto

Este projeto simula um pequeno sistema de cadastro de clientes, explorando os principais componentes disponibilizados pela biblioteca CustomTkinter.

Durante o desenvolvimento foram praticados conceitos como:

* Organização da interface utilizando Classes;
* Programação Orientada a Objetos (POO);
* Gerenciamento de Layout com **Grid** e **Pack**;
* Criação de múltiplas abas utilizando **CTkTabView**;
* Barra lateral personalizada;
* Alternância entre **Modo Escuro** e **Modo Claro**;
* Componentes interativos como:

  * CTkEntry
  * CTkButton
  * CTkLabel
  * CTkRadioButton
  * CTkCheckBox
  * CTkOptionMenu
  * CTkSlider
  * CTkProgressBar
  * CTkSwitch
* Atualização dinâmica dos elementos da interface.

##  Funcionalidades

* Cadastro de perfil do usuário;
* Seleção do nível de acesso (Básico ou Administrador);
* Configuração de preferências do sistema;
* Controle de volume por Slider;
* Barra de progresso simulando o carregamento do sistema;
* Navegação entre abas;
* Alteração do tema da aplicação (Dark/System).

## Tecnologias utilizadas

* Python 3
* CustomTkinter
* Programação Orientada a Objetos (POO)
