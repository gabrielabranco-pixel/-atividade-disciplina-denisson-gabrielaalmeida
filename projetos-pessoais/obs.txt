O que é um Callback?

Um callback é uma função que é passada como argumento para outra função, para que ela seja executada em um momento específico.

Em outras palavras:

Você entrega uma função para outra função e diz: "quando terminar sua tarefa, chame esta função".

É exatamente por isso que ela recebe o nome callback:

call = chamar
back = de volta

Ou seja:

"Me chame de volta quando terminar."

Exemplo do mundo real

Imagine que você pede uma pizza.

Você diz ao atendente:

"Quando a pizza chegar, me ligue."

Você não fica parado esperando.

A pizzaria faz todo o trabalho e, quando termina, ela executa o "callback":

📞 "Sua pizza chegou!"

Nesse exemplo:

A pizzaria = função principal
A ligação = callback
Exemplo simples em Python

Sem callback:

def saudacao():
    print("Olá!")

saudacao()

Saída:

Olá!
--------------------------------------------------------------------------------------------------
Agora usando callback:

def executar(funcao):
    print("Executando...")
    funcao()

def saudacao():
    print("Olá!")

executar(saudacao)

Saída:

Executando...
Olá!
-----------------------------------------------------------------------------------
def soma(a, b, callback):
    resultado = a + b
    callback(resultado)

def mostrar(valor):
    print("Resultado:", valor)

soma(5, 3, mostrar)

Saída

Resultado: 8
-------------------------------------------------------------
Um callback é:

Uma função passada como argumento para outra função.
Executada posteriormente, quando a função principal decidir.
Muito usada em eventos, interfaces gráficas, temporizadores, requisições de rede e programação assíncrona.
Em Python, você passa a referência da função sem parênteses (minha_funcao), e a executa depois com minha_funcao().
